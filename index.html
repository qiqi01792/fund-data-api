基金数据只读接口

公开行情数据，只读。仅含正式单位净值，不含任何持仓信息（无金额、份额、成本、盈亏、账户资产与交易记录）。

可用端点

端点内容
/api/fund_summary.json21 只基金汇总字段 + 分位口径 + 异常记录
/api/fund_nav_series.json汇总 + 近 1 年每日净值序列（全部基金合并，体积大）
/api/nav/<基金代码>.json单只基金近 1 年每日净值序列（如 /api/nav/000218.json）
/api/history/<基金代码>/index.json单只基金成立以来完整历史的分页索引（总条数/总页数/首末日）
/api/history/<基金代码>/page/<n>.json完整历史第 n 页（每页 150 条，按日期升序，可无缝拼接）
/api/valuation.json基金估值明细（V6.2 第三维：估值状态 / PE / PB / 股息率 / PE·PB 历史分位 / 估值评分 / 基准指数与匹配质量）
/api/rules.json基金管理系统策略规则 V6.3（唯一版本：核心阈值 + 定投计划 + 版本演进表 + 全文分页索引；2026-10-12 起完整正文改由 /api/rules_fulltext/page/ 分页提供，正文一字不删）
/api/rules_core.json策略规则结构化核心（轻量版：阈值/公式/定投计划/待确认清单，约 20KB，ChatGPT 日常入口）
/api/rules_fulltext/index.json + /api/rules_fulltext/page/{n}.json规则完整全文分页（含历史归档章节）
/api/performance.json21 只基金多窗口业绩指标（1m/3m/6m/1y/3y/5y/10y/成立以来 收益率、最大回撤、年化波动率）
/api/signals.json每日操作信号（评级 A/B/C/D、补仓档位与资格判定、2000 元资金池结论、禁止补仓列表 + V6.1 累计止盈 + V6.2 三维估值决策：历史位置/近6月位置/估值三关过滤与综合评分 + 定投启停 + 口径分歧警示）
2026-10-12 C2：公开通道不输出账户相关金额（补仓金额、月池已用/剩余均已移除），只给结论；同日起瘦身以适配客户端响应上限，ChatGPT 请优先用 /api/signals_brief.json
/api/signals_brief.json每日操作信号精简版（保留全部决策字段，剥离长文案；ChatGPT Actions 日常入口）
/openapi.jsonChatGPT 自定义 GPT Action 描述文件（版本 2.4.0）

数据范围与限制

合并净值序列文件仅覆盖近 1 年；成立以来完整历史通过全历史分页端点对外公开 （先取 index.json 再逐页取 page/<n>.json，每页 150 条）。
静态托管不支持带参数的服务端查询（start_date/end_date 无效）；日期范围过滤请由调用方在客户端按 nav_date 完成。
